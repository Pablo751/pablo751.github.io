Master Processor

Architect and engineer for Scotspeed, UK

A car mat manufacturer sells made-to-order mats for thousands of vehicle models on four marketplaces. Every order has to become the right carpet, trim, clips and embroidery on the factory floor, and every listing has to fit the right cars.

  • My earlier Python system already handled €3M+ a year and 10,000+ orders a month, and saves 3 to 4 hours of manual work every day.
  • The Master Processor brings everything into one platform, connected directly to the Amazon SP-API, eBay, Shopify and Temu APIs.
  • Pulls orders from every store, matches each SKU against a reference database of almost 100,000 Amazon SKUs, generates production files and barcodes, and uploads tracking back to each channel.
  • Manages listings at scale: bulk product uploads to Amazon, bulk image updates with a safe mode and rollback, stock and pricing across channels.
  • Keeps vehicle compatibility right: harvests and repairs K-type data so each mat appears for exactly the cars it fits.
  • Temu runs through a dedicated relay with a static IP, as its API requires, and parcel tracking comes from the courier through Scurri.
  • TypeScript
  • NestJS
  • Next.js
  • MongoDB
  • Turborepo
  • Amazon SP-API
  • eBay API
  • Temu API
